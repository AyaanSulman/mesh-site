# ObscuraNet

**Secure. Private. Decentralized.**

ObscuraNet is a high-performance, hardware-accelerated scrollytelling experience showcasing a modular, decentralized messaging protocol designed for secure, private peer-to-peer communication.

## 🚀 Key Features

- **Protocol Scrollytelling**: An immersive 12,000vh journey through the 40-step message lifecycle.
- **Hardware Accelerated**: Optimized with Framer Motion and `will-change-transform` for 60FPS performance.
- **Dynamic HUD**: Real-time reactive terminal interface with CRT effects and scanlines.
- **Cryptographic Visuals**: 3D Proof of Work (PoW) Rubik's solve and multi-layered Onion Routing visualization.
- **Deep Dive Insights**: Data-driven exploration of the global privacy crisis and censorship trends.

## 🛠 Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Typography**: JetBrains Mono

## 💻 Getting Started

1. **Clone and Install**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Explore**: Open [http://localhost:3000](http://localhost:3000) and scroll down to begin the journey.

## 🛡 Security Vision

ObscuraNet eliminates single points of failure by leveraging:
- **DHT (Distributed Hash Table)** for decentralized peer discovery.
- **ChaCha20 + X25519** for state-of-the-art encryption.
- **Multi-Hop Onion Routing** to obfuscate traffic origin and destination.
- **Proof of Work (PoW)** to mitigate spam and Sybil attacks.
